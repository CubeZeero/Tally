# 変更履歴

Tally のリリース履歴です。各バージョンは
[GitHub のタグ](https://github.com/CubeZeero/Tally/tags) に対応します。

## v1.2.0 — 2026-11-24 { #v120 }

### 新機能

- **MCP 連携** — AI アシスタントからサブスク検索・集計・支払い予定を取得できます。OAuth で書き込みを許可すると、サブスクの登録・編集・停止・再開・複製や、カテゴリ・支払い方法の管理ができます。[MCP 連携](mcp.md)
- **REST API** — サブスクの取得・登録・編集・削除に対応しました。期間内の請求明細、トライアルと見直し期限、カテゴリ・支払い方法別の集計、CSV・JSON のインポートプレビューも利用できます。[REST API](rest-api.md)
- **開発版の表示** — 情報タブに開発版ラベルを表示し、同じバージョン番号の正式版が公開されると更新を検出します。

### セキュリティと改善

- Web セッションと MCP の OAuth トークンを分離し、OAuth の書き込み権限は明示的な許可を必須にしました。
- API キーをハッシュ化し、更新済みの依存関係、リクエストサイズ制限、HTTP セキュリティヘッダーを適用しました。Docker は初期化後に非 root で動作します。
- 支払い日の計算を共通化し、設定の自動保存を順序どおりに処理します。インポートの上書きに失敗した場合は、既存データを保持します。

### 更新前に確認

- **LAN・Tailscale** — Docker Compose は従来どおり既定で全インターフェースにポート `6400` を公開します。特定の IP に限定したい場合は、任意で `.env` に `TALLY_BIND_ADDRESS` を設定できます。
- **ログインと MCP** — 更新後は再ログインと OAuth の再認可が必要です。旧キー埋め込み URL は `/api/mcp` と Bearer ヘッダーに切り替えてください。既存の API キーはヘッダーで引き続き使えます。
- **通知とアカウント登録** — カスタム Webhook とユーザー別 SMTP の接続先は許可リストへの登録が必要です。初回アカウント作成後も新規登録を開く場合は `DISABLE_REGISTRATION=0` を設定します。

詳しい手順は[はじめに](getting-started.md)と[セルフホスト](self-hosting.md)を参照してください。

## v1.1.2 — 2026-07-18

- **設定の自動保存** — 保存ボタンを廃止し、変更すると即座に保存されるように
  （テキスト入力はデバウンス）。パスワードは専用ボタンで変更します。
- **アクセントカラー** — 設定からスウォッチで選択（ライト/ダーク対応）。
- ページ遷移フェードを有効化したときのチラつきを修正。
- アニメーション/フェードのスイッチが保存後にずれる問題を修正。
- 「テスト送信」が保存済みの値ではなく、入力中の Webhook でテストされるよう修正。
- ダッシュボードの装飾サークルの位置を調整。

## v1.1.1 — 2026-07-17

- **手動アップデートチェック** — About ページの「更新を確認」ボタンで、6時間
  キャッシュを無視して即座に最新版を確認できるようになりました。
- バージョン表記を読みやすいピル表示に改善。

## v1.1.0 — 2026-07-17

- **アップデート通知** — 新しいバージョンが GitHub に出ると、アプリ上部にバナーを
  表示します（About ページにも現行/最新バージョンを表示）。環境変数
  `UPDATE_CHECK=0` で無効化できます。
- **データ保存先の指定** — `TALLY_DATA_DIR` で DB とバックアップを任意のホスト
  ディレクトリ（外部ストレージなど）に保存できるようになりました。
- About ページにホームページ（ドキュメント）へのリンクを追加。
- ドキュメント整備 — 初回設定を前に集約、カスタムドメイン `tally.cubezeero.com`。

## v1.0.0 — 2026-07-16

初回リリース。

- **サブスク管理** — 料金・請求サイクル・次回支払日、月額/年額の自動集計、無料
  トライアル、複製、解約検討リマインド、検索・フィルタ・並べ替え。
- **多通貨** — メイン通貨へ自動換算（英語サインアップは USD、日本語は JPY を既定）、
  月間予算と予算超過アラート。
- **通知** — Discord / メール / 汎用 Webhook / Slack / ntfy（内蔵スケジューラーで
  毎日自動送信、cron 不要）。
- **iCal 連携**、カレンダー表示、統計（円グラフ・折れ線）。
- **PWA**（ホーム画面に追加）、**自動バックアップ**（SQLite `VACUUM INTO`）。
- マルチユーザー、日本語 / English、ダーク / ライト、コンポーネントアニメーション
  とページ遷移フェード。
