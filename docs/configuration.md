# 設定

Tally の設定は2種類あります。**サーバー側の環境変数**（コンテナ起動時に指定）と、
アプリの設定画面で変更する**ユーザーごとのオプション**です。

!!! info "環境変数は「はじめに」にまとめています"
    `SESSION_SECRET`・`TZ`・`DISABLE_REGISTRATION`・`SMTP_*`・`BACKUP_*` などの
    サーバー側環境変数の一覧と `.env` の書き方は、初回起動前に設定するため
    [はじめに](getting-started.md) にまとめています。

## ユーザーごとの設定（アプリ内）

アプリの **設定** 画面で以下を変更できます:

- **言語** — 日本語 / English（ユーザーごと。サインアップ時にも選択）
- **メイン通貨** — 他通貨はこの通貨に換算して集計（初期値はサインアップ言語から
  推定: English → USD / 日本語 → JPY）
- **月間予算** — ダッシュボードの予算バー・予算超過通知に使用
- **通知** — Discord / メール（＋ユーザーごと SMTP）/ 汎用 Webhook / Slack /
  ntfy、送信時刻・何日前（折りたたみセクション）
- **iCal カレンダー連携** — フィード URL の発行・再生成・無効化
- **バックアップ** — 状態確認と手動バックアップ
- **カテゴリ・支払い方法** — 編集可能なリスト（選んだ言語で初期化）
- **為替レート** — 手動更新
- **パスワード** — アカウントのパスワード変更

## 公開インスタンスのロックダウン

Tally をインターネットに公開する場合:

1. 強い `SESSION_SECRET` を設定する（[はじめに](getting-started.md) を参照）。
2. `DISABLE_REGISTRATION=1` に設定し、`docker compose up -d` で反映する。`v1.2.0` 以降ではこれが既定値です。
3. HTTPS の背後に置く（リバースプロキシまたは Tailscale）。Tally は
   `x-forwarded-proto: https` を検知すると、自動でセッション Cookie に
   `Secure` を付与します。
